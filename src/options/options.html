这些字段会在一键填充时写进网页表单，只保存在本机 chrome.storage.local。

基本信息

姓名建议同时填写全名与「姓 / 名」，以适配不同 ATS 的字段拆分。

自定义字段

内置字段不够用时在这里加，例如「期望薪资 / expected_salary」「到岗时间 / available_date」。 key 由 label 自动生成，也可以手动改；纯中文 label 会得到 custom_field_1 这样的兜底 key。 自定义字段不会写进内置字典，需要到下方「映射规则」或用 popup 的「从当前页学习」告诉插件怎么识别。

映射规则

用户规则优先于 ATS 精确规则和内置字典：命中即按规则填，不再猜。 匹配文本会先归一化（忽略大小写、空格、标点），regex 则对归一化后的文本执行。

数据管理

导出的 JSON 可以备份或迁移到另一台设备；导入会覆盖当前内容（含自定义字段）。
