# JustClick 手动验收指南

自动测试之外的真实浏览器验收步骤（约 5 分钟）。

## 1. 加载插件

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库的 **`dist/`** 目录
4. 工具栏出现 JustClick 图标即成功

## 2. 填写简历

1. 点击 JustClick 图标 → 「打开设置」
2. 填写：姓、名、邮箱、电话（至少这四项）
3. 保存（提示已保存）

## 3. 真实页面验收

| 站点 | 测试页 | 预期 |
|---|---|---|
| Greenhouse | 任意职位页「Apply」表单 | 姓/名/邮箱/电话填入并高亮，开放问题不动 |
| Lever | 任意职位页「Apply for this job」 | 同上 |
| Workday | 职位页「Apply」登录前的基本信息页 | 邮箱/姓名填入 |
| Boss直聘 | 职位沟通弹窗（如有表单） | 手机号填入 |

验收要点：
- ✅ 点击 JustClick → 一次填充所有匹配字段
- ✅ 已填字段金色高亮约 2 秒
- ✅ popup 显示缺失字段清单（如 lastName 未填）
- ❌ 开放问题（"Why do you want to work here?"）绝不能被乱填

## 4. 已知边界（MVP 不做）

- 需要登录后的 Workday 深层多步表单
- 自定义问题的语义填写（后续迭代：TypeSafe 语义匹配）
- 简历文件（PDF）导入
